cyberdesign

A cyber/terminal design system — neon glow, CRT scanlines, augmented clip-path panels, JetBrains Mono. Powers ocint and robostrudel, and any other project that wants to look like a control room instead of a spreadsheet. CSS tokens and components, thin React bindings, full Storybook.

What it is
  • 60+ components — forms, overlays, navigation, charts, terminal & HUD families
  • Five accent themes, class-switched on <html>: orange, cyan, green, red, steel
  • JetBrains Mono throughout; augmented clip-path corners instead of border-radius
  • Pure CSS core (cyberdesign) + thin React bindings (react-cyberdesign)
  • MIT licensed
