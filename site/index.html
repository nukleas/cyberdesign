What it is

  • 60+ components — forms, overlays, navigation, charts, terminal & HUD families
  • Five accent themes, class-switched on <html>: orange, cyan, green, red, steel
  • JetBrains Mono throughout; augmented clip-path corners instead of border-radius
  • Pure CSS core (cyberdesign) + thin React bindings (react-cyberdesign)
  • MIT licensed
