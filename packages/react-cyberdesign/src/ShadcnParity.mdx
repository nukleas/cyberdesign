# Shadcn base component parity

onto cyberdesign CSS with semantic props.

`Ticker`, `Scanner`, `Interference`, `AugButton`, `AugPanel`, `Stat`, `PanelHeader`.

Newer shadcn chat primitives (Attachment, Bubble, Message, …) are intentionally out of scope for now.
