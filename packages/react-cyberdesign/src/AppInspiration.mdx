# Inspiration: dashboard & AI-shell apps

cyberdesign was extracted so a civic-intel-style dashboard app and an AI-shell/REPL-style app
could share one terminal/cyber visual language. This library pulls the reusable **app patterns**
back up as typed components.

## Dashboard app patterns

| App pattern | Component(s) | Source cues |
| --- | --- | --- |
| Column section titles | `SectionHeader` | `▸ INTEL FEED` / `▸ METRICS` |
| Metric tiles | `Stat` / `StatGrid` + `GlowCard` | stats panel |
| Category / near filters | `Chip` / `ChipRow` | feed filter bar |
| Live system indicator | `StatusDot` | header `SYS.ACTIVE` |
| Situation severity | `StatusPill` | situation hero |
| Feed list rows | `Feed` / `FeedItem` | intel feed |
| Category breakdown | `HBar` | stats "BY CATEGORY" |
| Mobile tabs | `BottomNav` | mobile tab bar |
| Header clock | `Clock` | header live time |
| Side detail panel | `Sheet` | item detail drawer |

Domain-specific (stays out of this library): map chrome, time histogram scrubber, dossier
sections, location picker.

## AI-shell app patterns

| App pattern | Component(s) | Source cues |
| --- | --- | --- |
| Play / stop cluster | `Transport` | header transport group |
| AI chat rail | `Chat` / `ChatMessage` | AI panel |
| Quick prompt chips | `Chip` in `Chat` prompts | quick-prompt row |
| Footer status | `StatusBar` | status bar + prompt cursor |
| Live / paused | `StatusDot` | live/paused indicator |
| Panel title bar | `PanelHeader` | shared sweep header |
| Command palette | `Command` | command palette |
| File / corpus rows | `Item` / `FeedItem` | corpus entry list |

Domain-specific (stays out of this library): code editor, audio visualizer, MIDI lab, file tree,
BPM/gain sliders, recording pipeline.

## Composition recipes

**Dashboard column**

```tsx
<SectionHeader title="Metrics" actions={<StatusDot status="live">SYS.ACTIVE</StatusDot>} />
<StatGrid>
  <Stat label="Today" value={142} variant="accent" />
  <Stat label="7 day" value={891} />
</StatGrid>
```

**AI-shell**

```tsx
<Transport playing={playing} onPlay={…} onStop={…} />
<Chat title="AI" messages={…} prompts={…} onSubmit={…} />
<StatusBar message="ready" meta="track.strudel" />
```
